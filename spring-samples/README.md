# spring-samples

A small application module for exploring Spring Framework internals in this workspace.

## Run

From the repository root:

```bash
./gradlew :spring-samples:run
```

## What it does

- Creates an `AnnotationConfigApplicationContext`
- Defines a simple bean in `AppConfig`
- Retrieves and runs the bean from the Spring context

## Use it for learning

You can modify the sources in `spring-samples/src/main/java/org/springframework/samples` to experiment with Spring classes from the local workspace.
